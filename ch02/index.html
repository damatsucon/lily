1貯蓄のない経済：生産＝分配＝支出

いちばん単純な経済から始めます。登場するのは家計と企業の2つ、市場は財市場（モノ・サービスの市場）と生産要素市場（労働と資本の市場）の2つです。ここでは、市場は理想的に働き、需要と供給は必ず一致すると考えます。

下の図はボタンで4段階に切り替えられます。この節では「貯蓄なし」を見てください。

  • 家計は労働 L と資本 K を企業に提供し、賃金と利子・配当 wL + rK を受け取る。
  • 企業は K と L を使って生産する。この関係を生産関数 Y = F(K, L) と書く。
  • 家計は受け取った所得で、作られたモノを買う（消費 C）。
Y = wL + rKテキスト (2.3)

生産 ＝ 分配された所得（作った価値は、働いた人と資本を出した人にすべて分けられる）

Y = Cテキスト (2.2)

生産 ＝ 支出（作ったものは、すべて買われる。これが財市場の均衡条件）

この2つから、生産 ＝ 所得 ＝ 支出が成り立ちます。これを三面等価と呼びます。

メモ：島のパン屋で考えよう島にはパン屋が1軒だけ。島の人はパン屋で働いて給料をもらい、その給料でパンを買う。パン屋が1日に焼いたパンの値段の合計（生産）、島の人の給料と店主のもうけの合計（所得）、島の人がパンに払ったお金の合計（支出）は、みな同じ金額になる。

どんな経済でも、作った価値（生産）は誰かの所得になり、その所得で作ったものが買われる。生産＝所得＝支出（三面等価）。

2貯蓄と投資のある経済

家計は所得をすべて使うわけではありません。使わずに残した分が貯蓄 S です。

S ≡ Y − Cテキスト (2.5)

貯蓄 ＝ 所得 − 消費（≡ は「定義によって等しい」という記号）

一方、企業は作ったモノの一部を、自分で工場や機械として使います。これが投資 I です。経済学の投資は「株を買う」ことではなく、資本ストック（工場・機械）を増やすことを指します。

企業は投資のための資金が足りないので、家計の貯蓄を借ります。お金を貸し借りする場所が貸付資金市場です（図の②）。

Y = C + Iテキスト (2.4)

財市場の均衡：作った量 ＝ 消費 ＋ 投資

S = Iテキスト (2.6)

貸付資金市場の均衡：貸したいお金（貯蓄）＝ 借りたいお金（投資）

2つの均衡条件は同じことを言っている

(2.4) の Y に C + S（貯蓄の定義を移項したもの）を入れると、C + S = C + I、つまり S = I です。逆も同じように導けます。財市場の均衡と貸付資金市場の均衡は同値（片方が成り立てば、必ずもう片方も成り立つ）です。

所得 Y
消費 C　400
貯蓄 S　100
支出 Y
消費 C　400
投資 I　100

単位：兆円（架空の値）。所得500のうち400を消費し、100を貯蓄する。財市場で需要と供給が一致する（支出も500）なら、投資も100になり、貯蓄と一致する。

この関係は 課題 問3 で使います

貯蓄は所得のうち使わなかった分。財市場の均衡（Y = C + I）と貸付資金市場の均衡（S = I）は同じことを表す。

3政府のある経済

政府は家計から税 T を集め、政府支出 G を行います（図の③）。財市場での需要は、消費・投資・政府支出の3つになります。

Y = C + I + Gテキスト (2.7)

財市場の均衡：作った量 ＝ 消費 ＋ 投資 ＋ 政府支出

家計が自由に使えるのは、税を払った後の所得 Y − T（可処分所得）です。貯蓄は、民間と政府に分けて考えます。

名前式意味

公的貯蓄 SGT − G税収のうち、政府が使わなかった分。マイナスなら財政赤字
国民貯蓄 SSP + SG = Y − C − G国全体の貯蓄
S = SP + SG = Y − C − Gテキスト (2.8)

国民貯蓄 ＝ 民間貯蓄 ＋ 公的貯蓄（税 T は家計から政府へ移るだけなので、合計すると消える）

貸付資金市場の均衡は、ここでも S = I（テキスト (2.9)）で、財市場の均衡 (2.7) と同値です。

国民貯蓄＝民間貯蓄（Y−T−C）＋公的貯蓄（T−G）。財政赤字は公的貯蓄のマイナス。閉じた経済では国民貯蓄＝投資。

4外国のある経済（開放経済）

外国とモノを売り買いすると、国内で作ったモノ（自国財）と外国で作ったモノ（外国財）を区別する必要があります（図の④）。

  • 国内の人が自国財に使う額 ＝ C + I + G − 輸入 IM
  • 外国の人が自国財に使う額 ＝ 輸出 EX
Y = C + I + G + NXテキスト (2.10)

作った量 ＝ 国内の需要（内需）＋ 純輸出（外需）。NX ＝ EX − IM

純輸出がプラスの国は、作ったより少なく使っているので、余りを外国に貸しています。外国に対する「貯金」を対外純資産、その1年間の増加を経常収支 CA と呼びます。最初の対外純資産がゼロなら、CA = NX（テキスト (2.11)）です。

S = I + CAテキスト (2.12)

国民貯蓄は、国内で投資に貸し出されるか（I）、外国に貸し出されるか（CA）のどちらか

5GDP は「付加価値の合計」

GDP（国内総生産）は、ある一定期間に国内で生産された最終生産物の価値の合計です。いろいろな財の数量を、市場価格を重みにして足し合わせます。

Y = p¹q¹ + p²q² + ⋯ + pⁿqⁿテキスト p.36

GDP ＝ 各財の（価格 × 数量）の合計。i 番目の財の価格が pⁱ、数量が qⁱ

市場価格を重みに使うのは、価格に消費者の評価（限界便益、第1章）が表れていると考えるからです。

中間生産物は数えない

農家が小麦を作って製粉業者に100万円で売り、製粉業者が小麦粉にしてパン屋に150万円で売り、パン屋がパンにして消費者に200万円で売ったとします（テキスト図2.3）。

単位：万円。黄色が各段階で新しく生み出された価値（付加価値）。

  • 付加価値 ＝ 売上 − 原材料などの仕入れ。その段階で新しく生み出した価値。
  • 小麦・小麦粉・パンの売上を全部足すと450万円ですが、これは小麦の価値を3回、小麦粉の価値を2回数えてしまいます（二重計算）。
  • GDP は最終生産物のパンの200万円で、これは各段階の付加価値の合計に等しい。

GDP は最終生産物の価値の合計＝各段階の付加価値の合計。途中で使われる中間生産物は数えない。

6グロスとネット、市場で取引されないもの

グロス（粗）とネット（純）

機械や建物は、使うと少しずつ傷みます。この目減りを資本減耗と呼びます。資本減耗は推計が難しいので、GDP は資本減耗を差し引かないグロス（総・粗）の値です。差し引いたネット（純）の値が国内純生産（NDP）です。

NDP = GDP − 資本減耗テキスト p.38

市場で取引されないものはどう扱うか

ものGDP での扱い
政府のサービス（警察、国防など）市場価格がないので、かかった費用で評価して含める
持ち家に住むこと家賃を払ったものとみなして推計し、含める（帰属家賃）
農家が自分で食べる野菜推計して含める（帰属計算）
家事労働推計が難しいので含めない
公害、環境汚染本来はマイナスとして数えるべきだが、考慮されていない
メモ：帰属家賃がないとどうなる？同じ家に同じように住んでいても、借家なら家賃が GDP に入り、持ち家なら入らない。すると「みんなが家を買うと GDP が減る」という変なことが起こる。帰属家賃はこれを防ぐための工夫。

政府サービスを費用で評価することの問題は 課題 問5 で考えます

GDP は資本減耗を引かないグロスの値。市場取引がないものは、費用や推計で評価して含めるが、家事労働や環境汚染は含まれない。

7GDP と GNI、国民所得

  • GDP（国内総生産）：日本の国内で生み出された価値。日本で働く外国人の生産は含み、外国で働く日本人の生産は含まない。
  • GNI（国民総所得）：日本の国民が得た所得。以前は GNP（国民総生産）と呼ばれた。
GNI = GDP + 海外からの所得の純受取テキスト p.41

海外からの所得の純受取 ＝ 日本人が海外から受け取る所得 − 国内の外国人が受け取る所得

8名目 GDP と実質 GDP

物価が上がると、作った量が同じでも GDP の金額は増えてしまいます。そこで2種類の GDP を使い分けます。

どの価格で評価するか式（時点 t）
名目 GDP PYtその年の価格pt¹qt¹ + ⋯ + ptⁿqtⁿ
実質 GDP Yt基準年（時点0）の価格に固定p0¹qt¹ + ⋯ + p0ⁿqtⁿ

実質 GDP は価格を固定しているので、量の変化だけを表します。経済活動の本当の水準を見るには、実質 GDP を使います。

GDP デフレータ ＝ 名目 ÷ 実質。ラスパイレスとパーシェは第11節で説明します。

名目 GDP = GDP デフレータ × 実質 GDPPYt = Pt · Yt

成長率で見ると、名目成長率 ≒ インフレ率 ＋ 実質成長率

連鎖方式

基準年から時間がたつと、財の値段の比（相対価格）が大きく変わり、固定した価格で測ると実態とずれていきます（パソコンの値下がりなど）。そこで現在の日本では、前年の価格で今年の実質成長率を求め、それを掛け合わせて実質 GDP を計算します。これを連鎖方式と呼びます。

Yt = Y0 × Γ0,1 × Γ1,2 × ⋯ × Γt−1,tテキスト p.43

Γs,s+1 は「時点 s の価格で測った、s から s+1 への（1＋実質成長率）」

名目 GDP はその年の価格、実質 GDP は基準年の価格で評価する。実質 GDP の変化は量の変化だけを表す。

11物価指数：ラスパイレスとパーシェ

物価は、いろいろな財の価格の「平均」的な水準です。基準時点0と比べた時点 t の物価は、各財の値上がり率（ptⁱ / p0ⁱ）に重み wi を付けた平均で表します（重みの合計は1）。

Pt = w1pt1p01 + w2pt2p02 + ⋯ + wnptnp0nテキスト (2.13)

物価 ＝ 各財の値上がり率の加重平均

重みの決め方で、2つの指数があります。整理すると、どちらも「同じ買い物かごを、今の価格と基準時点の価格で買ったときの金額の比」になります。

重み（どの買い物かごか）計算式（整理したもの）代表例
ラスパイレス指数基準時点の数量 q0 で固定Σptq0 / Σp0q0（テキスト (2.16)）消費者物価指数（CPI）
パーシェ指数比較時点の数量 qt を使うΣptqt / Σp0qt（テキスト (2.17)）GDP デフレータ
第8節の数値例（パン 100→120円、10→11個／映画 500円のまま、2→3回）
ラスパイレス：(120×10 + 500×2) ÷ (100×10 + 500×2) ＝ 2,200 ÷ 2,0001.100（物価10.0%上昇）
パーシェ：(120×11 + 500×3) ÷ (100×11 + 500×3) ＝ 2,820 ÷ 2,6001.085（物価8.5%上昇）

代替効果：なぜラスパイレスは高めに出るのか

値上がりした財（パン）を控え、値上がりしなかった財（映画）を多く買うのが普通です（代替効果）。ラスパイレス指数は基準時点の買い物かごのままなので、この行動を反映せず、生活費の上昇を大きめに評価します。一方、パーシェ指数は代替効果を反映しますが、値上がりによる実質的な購買力の変化までは反映しません。

上の数値例でも、ラスパイレス（10.0%）のほうがパーシェ（8.5%）より高くなっています。第8節のスライダーで、ほかの組み合わせも試してください。

ラスパイレスは基準時点の買い物かご、パーシェは今の買い物かごで測る。代替効果のため、ラスパイレス（CPI）は高めに出る。

差

名目5%・インフレ2%なら実質約3%。名目0%でもデフレ（−2%）なら実質約2%（テキスト p.54 の例）。

フィッシャー方程式

i = r + πᵉフィッシャー方程式

名目利子率 ＝ 実質利子率 ＋ 予想インフレ率（期待インフレ率）

合理的な家計や企業にとって大切なのは、名目ではなく実質利子率です。古典派モデルでは、実質利子率は実物経済（貯蓄と投資）で決まり、そこに予想インフレ率が上乗せされて名目利子率が決まると考えます。実物と名目が別々に決まるという考え方を古典派の二分法と呼びます。

実質利子率 ≒ 名目利子率 − インフレ率。フィッシャー方程式：名目利子率＝実質利子率＋予想インフレ率。

14失業率の定義

完全失業率 = 完全失業者数労働力人口テキスト p.56

働く意欲のある人のうち、仕事が見つかっていない人の割合

  • 労働力人口 ＝ 15歳以上のうち、就業者（休業者を含む）と完全失業者の合計。
  • 完全失業者：仕事がなく、仕事があればすぐ就くことができ、実際に仕事を探している人。
  • 非労働力人口：学生、家事に専念する人、引退した高齢者など、仕事を探していない人。失業者には数えない。
15歳以上の人口

職探しをあきらめた人は非労働力人口に移るので、失業率は下がって見えます。失業率の数字だけで景気を判断するときは注意が必要です。また、失業の定義は国によって違うので、単純な国際比較もできません。

失業率＝完全失業者÷労働力人口。職探しをあきらめた人は労働力人口から外れ、失業率に数えられない。

15失業はなぜ生まれるか、フィリップス曲線

種類理由考え方
摩擦的失業転職や、古い産業から新しい産業への移動のあいだに、一時的に生まれる失業古典派。経済が変化している健全さの表れで、問題にすべきものではない
非自発的失業働きたいのに仕事がない。総需要が足りず、しかも賃金が下がりにくい（賃金の下方硬直性）ので解消しないケインズ派

なぜ賃金が下がりにくいのかを、現代のニュー・ケインジアンはミクロ経済学で説明します。

  • 情報の非対称性（逆選択）：働く人の能力を、雇う企業はよく知らない。賃金が平均的な能力に合わせて決まると、能力の高い人が転職市場に出てこなくなり、市場がうまく働かない。
  • 効率賃金：賃金を下げると働く人のやる気が下がり、かえって企業の利益が減る。だから失業があっても賃金を下げない。

フィリップス曲線

失業率とインフレ率のあいだには、失業率が低いときほどインフレ率が高いという負の関係が見られます。これをフィリップス曲線と呼びます。日本のデータ（1971〜2019年）でも、この関係が見られます（テキスト図2.10）。

1970年代の高インフレ期には、多くの国で安定したフィリップス曲線が見られなくなりました。その論争から、予想インフレ率に応じて曲線が動くという考え方や、長期的には曲線は垂直になるという自然失業率仮説が生まれました（第10章）。また近年は、フィリップス曲線が平らになっていると言われます。

失業には摩擦的失業と非自発的失業がある。失業率とインフレ率には負の関係（フィリップス曲線）があるが、予想インフレ率で曲線は動く。

19問1：財政赤字が増えると、国内投資はどうなるか

問題

公的貯蓄と民間貯蓄は、それぞれが無関係に決まっているとしよう。財政赤字の拡大は、公的貯蓄を減らし、国民貯蓄を減少させる。このとき、国内投資はどうなるだろうか。

ヒント閉鎖経済では S = I が成り立ちます。国民貯蓄 S が減ると、I はどうなるでしょうか。貸付資金市場でお金を貸したい量が減ったとき、お金の「値段」である利子率はどう動くでしょうか。

復習：パート1「政府のある経済」

解説と答案例は、まだ公開されていません。

手順1何が変わり、何が変わらないか

政府が支出を20増やし（G：100 → 120）、税はそのまま（T = 100）とします。財政赤字が20生まれます。

項目変わる？理由
公的貯蓄 SG = T − G20 減る0 → −20
民間貯蓄 SP変わらない問題の仮定（無関係に決まる）
国民貯蓄 S = SP + SG20 減る50 → 30

手順2貸付資金市場のどの線が動くか

貸付資金市場では、お金を貸す側が貯蓄 S、借りる側が投資 I です。投資は利子率が高いほど少なくなります（右下がり）。ここでは貯蓄は利子率によらないとして、垂直な線で描きます。国民貯蓄が減ると、S の線が左へ20動きます。

手順3グラフで読み取る

貸したいお金が減ったので、貸付資金市場で利子率が上がります（4% → 8%）。利子率が上がると、借りて工場を建てるのが割に合わなくなり、民間の投資が減ります。新しい均衡では、投資は国民貯蓄と同じ30になります。

数値例
国民貯蓄 S ＝ 50 + (100 − 120)30
投資 I ＝ 70 − 5r ＝ 30 となる利子率r ＝ 8%
投資の変化50 → 30（−20）

政府の借金（国債）が民間の投資のための資金を奪う、と考えることもできます。これをクラウディング・アウト（押しのけ）と呼びます。

手順4結論

よくある間違い　「政府支出が増えると景気がよくなり、投資も増える」と答えてしまうこと。この問題は、市場が均衡し S = I が成り立つ閉鎖経済を考えています。国民貯蓄が減れば、投資に回せるお金も同じだけ減ります。

国民貯蓄が減った分だけ国内投資が減る。貸付資金市場で利子率が上がり、民間投資が押しのけられる（クラウディング・アウト）。

閉鎖経済では貸付資金市場の均衡条件 S = I が成り立つ。民間貯蓄 SP が公的貯蓄と無関係に決まるとすると、財政赤字の拡大による公的貯蓄 SG = T − G の減少は、そのまま国民貯蓄 S = SP + SG を同じだけ減少させる。

貸付資金市場では資金の供給が減るので利子率が上昇し、投資は利子率の減少関数であるから民間投資が減少する。新しい均衡では投資は減少した国民貯蓄に等しくなり、国内投資は国民貯蓄の減少分だけ減少する（クラウディング・アウト）。

20問2：公的貯蓄と民間貯蓄は連動するか

問題

公的貯蓄と民間貯蓄が連動して決まるメカニズムはあるだろうか？

ヒント政府が今年減税して財政赤字を出すと、その借金はいつか返さなければなりません。返すのは誰でしょうか。将来の増税を予想した家計は、今年増えた手取りをどうするでしょうか。

復習：パート1「政府のある経済」

解説と答案例は、まだ公開されていません。

手順1減税で財政赤字が生まれるとする

政府支出はそのまま（G = 100）、税を20減らす（T：100 → 80）とします。公的貯蓄は 0 → −20 です。家計の手取り（可処分所得）は20増えます。

手順2家計は将来の増税を予想する

政府の借金は、将来の増税で返すしかありません。家計がそれを見越すと、今年増えた手取りは「将来の増税のための貯金」として残し、消費は増やしません。すると、公的貯蓄が減ったのと同じだけ、民間貯蓄が増えます。

減税前
民間貯蓄 50
公的貯蓄 0 → 国民貯蓄 50
減税後
民間貯蓄 70
公的貯蓄 −20
国民貯蓄 70 − 20 ＝ 50（変わらない）

単位：兆円（架空の値）。家計が消費を変えなければ、民間貯蓄は 500 − 80 − 350 ＝ 70 に増え、公的貯蓄の減少をちょうど打ち消す。

この考え方をリカードの等価定理（リカードの中立命題）と呼びます。第5章で、一時的な減税が純輸出を変えなかったのも同じ理由です。

手順3ほかにもある連動の仕組み

  • 政府支出がずっと増える場合：将来もずっと増税が続くと予想すると、家計の生涯の手取り（恒常所得）が減り、消費が減る（第5章の恒常的な政府支出）。
  • 利子率を通じた連動：財政赤字で利子率が上がると（問1）、貯金の得が大きくなり、家計が消費を減らして貯蓄を増やすこともある。

ただし、家計が本当に将来の増税まで見越して行動するかには議論があります。手元のお金が少なく借りることもできない家計や、将来の税を払うのが自分ではないと考える家計は、減税されると消費を増やすかもしれません。

手順4結論

よくある間違い　「公的貯蓄と民間貯蓄は別の主体が決めるので、関係はない」と答えてしまうこと。家計は政府の借金がいずれ自分たちの税で返されることを考えて行動できる、という点がポイントです。

ある。家計が将来の増税を予想すると、減税で財政赤字が増えても民間貯蓄が同じだけ増え、国民貯蓄は変わらない（リカードの等価定理）。ただし成り立つかどうかには議論がある。

政府が減税によって財政赤字を拡大させた場合、その債務は将来の増税によって返済されなければならない。家計がこの将来の増税を予想して行動するならば、減税で増えた可処分所得を消費に回さず貯蓄するため、公的貯蓄の減少と同額だけ民間貯蓄が増加する。その結果、国民貯蓄は変化しない。これをリカードの等価定理という。

このほか、政府支出の恒常的な増加が将来の増税を予想させて恒常所得を減らし消費を減らす経路や、財政赤字による利子率の上昇が民間貯蓄を増やす経路も考えられる。ただし、流動性制約に直面する家計や将来の税負担を考慮しない家計が多ければ、こうした連動は弱くなる。

21問3：なぜ一国全体では貯蓄と投資が一致するのか

問題

貯蓄主体と投資主体は異なるのに、なぜ一国全体では、貯蓄と投資が一致するのだろうか（閉鎖経済の場合）。

ヒント貯蓄 S ≡ Y − C の定義と、財市場の均衡 Y = C + I を組み合わせてみましょう。そのうえで、もし貯蓄したい額と投資したい額がずれていたら、何が動いて一致するのかを考えます。テキストは「古典派モデルとケインジアン・モデルで、S = I を実現するメカニズムは異なる」と述べています。

復習：パート1「貯蓄と投資のある経済」

解説と答案例は、まだ公開されていません。

手順1式の上では、財市場の均衡と同じこと

貯蓄の定義 S ≡ Y − C を、財市場の均衡 Y = C + I に入れると S = I になります。つまり財市場で作った量と使う量が一致していれば、貯蓄と投資は必ず一致します。逆に言えば、問題は「財市場の均衡（＝貯蓄と投資の一致）を実現するのは何か」です。

手順2古典派の答え：利子率が動く

家計がもっと貯蓄したくなり、貯蓄したい額が投資したい額を上回ったとします。お金を貸したい人が多いので、貸付資金市場で利子率が下がります。利子率が下がると投資が増え、貯蓄は減るので、両者は一致します。利子率が、お金の需要と供給をそろえる「価格」として働きます（第4章）。

手順3ケインズ派の答え：生産量（所得）が動く

価格や利子率がすぐには動かない世界では、家計が貯蓄を増やして消費を減らすと、モノが売れ残り、企業は生産を減らします。生産が減ると所得が減り、所得が減ると貯蓄も減ります。貯蓄が投資と同じ水準まで下がったところで、財市場は均衡します（第7章）。

ケインズ派の数値例（架空の値。消費 C = 50 + 0.8Y、投資 I = 50 で一定）
均衡：Y = 50 + 0.8Y + 50 よりY ＝ 500
貯蓄 S ＝ Y − C ＝ 500 − 45050（＝ I）
家計が節約し C = 30 + 0.8Y になると、Y = 30 + 0.8Y + 50 よりY ＝ 400
貯蓄 S ＝ 400 − 35050（＝ I のまま）

みんなが貯蓄を増やそうとしても、所得が減って、貯蓄の合計は投資と同じ50のまま変わらない（節約のパラドックス）。

手順4結論

よくある間違い　「統計上、S = I は必ず成り立つ恒等式だから」とだけ答えること。国民経済計算では売れ残りを「在庫投資」として数えるので、帳簿の上では一致しますが、それは財市場の均衡とは別の話です（テキスト p.30 の注2）。問われているのは、計画した貯蓄と計画した投資を一致させる仕組みです。

財市場の均衡は S = I と同値なので、財市場を均衡させる仕組みが貯蓄と投資を一致させる。古典派では利子率の調整、ケインズ派では生産量（所得）の調整による。

貯蓄の定義 S ≡ Y − C を財市場の均衡条件 Y = C + I に代入すると S = I が得られる。したがって、財市場の均衡と貸付資金市場の均衡は同値であり、一国全体で貯蓄と投資が一致するのは、財市場を均衡させるメカニズムが働くからである。

古典派モデルでは、価格が伸縮的であり、貸付資金市場で利子率が調整されることで、家計の計画貯蓄と企業の計画投資が一致する。ケインジアン・モデルでは価格が硬直的であり、生産量（所得）が調整されることで、貯蓄が投資の水準に一致する。なお、国民経済計算上で S と I が一致するのは、売れ残りを在庫投資に含めるという定義によるものであり、財市場の均衡とは区別して考える必要がある。

22問4：減税や政府支出の拡大は、なぜ貿易黒字を減らすのか

問題

貿易黒字を減らすために、国内の消費を拡大させる政策（減税）や政府支出を拡大させる政策が必要だと主張される場合がある。なぜ、こうした政策が貿易黒字を減らすのだろうか（テキスト p.35）。

ヒントS = I + NX を移項すると NX = S − I です。減税や政府支出の拡大は、民間貯蓄 SP と公的貯蓄 SG をそれぞれどう変えるでしょうか。

復習：パート1「外国のある経済」

解説と答案例は、まだ公開されていません。

手順1純輸出は「貯蓄 − 投資」

NX = S − I = (SP + SG) − I

国内で使い残したお金（貯蓄のうち投資に回らない分）が、外国への貸し付け＝純輸出になる

出発点は、Y = 500、T = 100、G = 100、C = 330、I = 50 とします（架空の値）。SP = 500 − 100 − 330 = 70、SG = 0、S = 70、NX = 70 − 50 = 20（黒字）です。

手順2それぞれの政策で何が変わるか

政策（20だけ）民間貯蓄 SP公的貯蓄 SG国民貯蓄 SNX（I = 50 のまま）
出発点70070＋20

どちらの政策も国民貯蓄を減らすので、投資が変わらなければ純輸出が減ります。国内でたくさん使うようになり、輸出に回していた分を国内で使う（または輸入が増える）と考えることもできます。

NX　20

国民貯蓄 S の行き先（単位：兆円、架空の値）。

手順3注意点：減税が効かない場合

問2のリカードの等価定理が成り立つと、家計は減税分を貯蓄に回すので、民間貯蓄が20増え、国民貯蓄も純輸出も変わりません。減税が貿易黒字を減らすのは、家計が減税分を消費に回す場合です。また、投資は小国の世界利子率で決まり、変わらないと考えています（第5章）。

手順4結論

よくある間違い　「消費が増えると輸入が増えるから」とだけ答えること。それも一面ですが、この問題では S = I + NX を使い、「国民貯蓄が減るから純輸出が減る」と説明することが求められています。

NX = S − I。減税（消費を増やす場合）や政府支出の拡大は国民貯蓄を減らすので、投資が変わらなければ純輸出（貿易黒字）が減る。

開放経済では S = I + NX が成り立ち、NX = S − I = SP + SG − I と書ける。政府支出の拡大は公的貯蓄 SG = T − G を減少させる。減税も公的貯蓄を減らし、家計が増えた可処分所得を消費に回すならば民間貯蓄は変化しないので、いずれの政策も国民貯蓄 S を減少させる。

国内投資 I が変わらなければ、国民貯蓄の減少分だけ純輸出が減少し、貿易黒字が縮小する。ただし、家計が将来の増税を予想して減税分を貯蓄する場合（リカードの等価定理）には、減税は国民貯蓄を変えず、貿易黒字も減らない。

23問5：政府サービスを費用で評価すると、GDP はどうずれるか

問題

政府サービスを供給費用で推計すると、限界便益でウェイト付けした正しい GDP と比べて、過大推計か過小推計か。(1) 安い費用で同じ量を供給できるようになった。(2) 必要性のないサービスのために新たに人を雇った。(3) 限界費用 c が一定のとき、供給が (a) 過大、(b) 過小、(c) 効率的な場合（テキスト p.40）。

ヒント正しい評価は「限界便益 × 数量」、統計での評価は「費用 × 数量」です。2つの「単価」である限界便益と費用（限界費用）のどちらが大きいかを比べましょう。限界便益は、量が増えるほど小さくなります。

復習：パート2「グロスとネット、市場で取引されないもの」、第1章「曲線の高さを読む」

解説と答案例は、まだ公開されていません。

手順12つの評価方法を並べる

単価評価額
正しい評価（ふつうの財と同じ）限界便益 MB（q 単位目の便益）MB × q
統計での評価費用 cc × q

つまり、c > MB なら過大推計、c < MB なら過小推計です。

手順2(1) と (2)

  • (1) 安い費用で同じ量：国民が受けるサービスは同じなので、正しい GDP は変わりません。しかし統計上は c × q が小さくなり、GDP が減ります。費用の削減（生産性の向上）が、GDP を減らして見せる＝過小推計になります。
  • (2) 必要のないサービスのために人を雇う：そのサービスの限界便益はゼロなので、正しい GDP は増えません。しかし統計上は人件費の分だけ GDP が増えます。過大推計です。

手順3(3) 供給量と効率的な水準を比べる

限界便益が MB = 10 − q、限界費用が c = 4（一定）の例で考えます（架空の値）。効率的な量は MB = c となる q* = 6 です。

ケースqMB(q)正しい評価 MB × q統計の評価 c × q判定
(a) 過大821632過大推計
(b) 過小462416過小推計
(c) 効率的642424ずれなし

手順4結論

よくある間違い　「正しい評価」を需要曲線の下の面積（総便益）としてしまうこと。問題文は「限界便益でウェイト付けした合計」、つまりふつうの財の GDP と同じく「価格（＝限界便益）× 数量」で評価すると言っています。

(1) 過小推計　(2) 過大推計　(3) 供給が過大なら MB < c で過大推計、過小なら MB > c で過小推計、効率的なら MB = c でずれはない。

正しい評価は限界便益と数量の積 MB(q)·q、国民経済計算上の評価は費用と数量の積である。(1) 供給量が不変なら限界便益で評価した価値は変わらないが、費用が下がると評価額は減少するので、GDP は過小推計となる。(2) 国民が必要と感じないサービスの限界便益はゼロであるが、人件費の分だけ評価額が増えるので、GDP は過大推計となる。

(3) 限界便益は逓減し、限界費用は c で一定であるから、効率的な供給量 q* では MB(q*) = c である。供給が過大（q > q*）なら MB(q) < c なので cq > MB(q)·q となり過大推計、供給が過小（q < q*）なら MB(q) > c なので過小推計となる。効率的な場合は MB(q*) = c なので、費用による評価は正しい値と一致する。
