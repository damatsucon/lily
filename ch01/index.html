1ミクロ経済学とマクロ経済学

経済学は大きくミクロ経済学とマクロ経済学に分かれます。違いは「どこを見るか」です。

ミクロ経済学マクロ経済学
見るもの一人ひとりの家計や企業、個々の市場国全体の経済
主な問い家計はどれだけ買うか、企業はどれだけ作るか、価格はどう決まるかGDP、物価、経済成長率、失業率はどう決まるか
たとえると森の中の1本1本の木森全体

マクロ経済学で扱う GDP や物価水準のように、国全体で合計・平均した数字を集計量と呼びます。

部分均衡分析と一般均衡分析

  • 部分均衡分析：ある1つの市場だけに注目して考える方法（例：コメの市場だけを見る）。
  • 一般均衡分析：いくつもの市場を同時に考える方法。

マクロ経済学は、財（モノ・サービス）の市場、労働の市場、お金の市場などを同時に考えるので、一種の一般均衡モデルと言えます。

経済循環図：お金とモノはぐるぐる回る

家計は労働や資本を企業に提供し、その見返りに賃金・利子・配当を受け取ります。企業は作ったモノを売り、家計はその所得で買い物をします。この図から、次の2つの関係が読み取れます。

Y = wL + rK生産と分配

作った価値は、すべて働いた人（賃金）と資本を出した人（利子・配当）に分けられる

Y = C生産と支出

作ったものは、すべて誰かに買われる（この単純な図では、買うのは家計の消費だけ）

ミクロは「木」、マクロは「森」を見る。マクロ経済学は、いくつもの市場を同時に考える一般均衡モデル。

2マクロ経済学の2つの考え方：古典派とケインズ派

マクロ経済学には、大きく2つの考え方があります。分かれ目は、「市場はうまく調整してくれるか」への答えです。

古典派ケインズ派
価格の動きすばやく動き、需要と供給はすぐに一致するなかなか動かない（硬直的）
何が何を決めるか供給が需要を決める（セイ法則）需要が供給を決める（有効需要の原理）
前提完全雇用（働きたい人はみな働けている）不完全雇用（失業が残りうる）
政策について裁量的な政策より、ルールに基づく政策不況なら財政政策・金融政策で需要を増やすべき
メモ：お店の値札で考えよう売れ残りが出たとき、すぐ値下げして売り切るお店ばかりなら「古典派」の世界。値札がなかなか変わらず、売れ残りや人手のだぶつきが続くなら「ケインズ派」の世界。

マクロ経済学でいう古典派は、ミクロ経済学の考え方をそのままマクロ経済に持ち込んだものです。古典派の世界では「物価はお金の量が決める」と考えます（古典派の二分法、貨幣ヴェール観）。

マクロ経済学の歩み

時期出来事
1930年代大恐慌。ケインズが「需要を刺激せよ」という処方箋を示し、ケインズ経済学が生まれる
1960年代までケインズ経済学の全盛期。サミュエルソンの新古典派総合（ケインズ流の政策で完全雇用を実現すれば、あとはミクロ経済学の分析が当てはまる）
1970年代スタグフレーション（不況とインフレが同時に起こる）でケインズ経済学が退潮。フリードマンのマネタリズム（ルールに基づく金融政策、k%ルール）、ルーカスらの合理的期待形成学派が台頭。「期待」と「ミクロ的基礎」の重要性が強調される
現代ニューケインジアン（市場の失敗を前提に、裁量的な政策に意味があると考える）、新しい古典派（リアル・ビジネス・サイクル理論：景気の波は技術などの実物的なショックで起こる）、新しい成長論（教育や研究開発が成長を生む）。どれもミクロ経済学的な基礎と、時間を通じた動きを扱う動学モデルを使う点は共通

この教科書では、両方の考え方を学びます。第4章・第5章の古典派モデルは「市場がうまく働く世界」、のちに学ぶケインズモデルは「価格が動きにくい世界」の話です。

古典派は「価格がすぐ調整される・供給が需要を決める」、ケインズ派は「価格は硬直的・需要が供給を決める」。

3経済学の考え方：モデルで考える

分析方法の特徴

  • 数学的なモデルとグラフをよく使う。
  • 理論モデルを作り、それが現実に合うかを統計データで確かめる。
  • 家計や企業は合理的に行動すると考える（合理的経済人の仮定）。社会全体の動きも、一人ひとりの行動から説明しようとする（方法論的個人主義）。

モデルの役割

メモ：モデルは地図のようなもの地図は現実をそのまま写さない。駅までの道を知りたいなら、建物の色や木の本数は省いた地図のほうが役に立つ。経済のモデルも、目的に合わせて大胆に単純化している。
  • 現実は複雑なので、単純なモデルで理解する必要がある。複雑すぎるモデルは扱えず、何も説明できない。
  • モデルが違えば結論も違う（例：財政政策の効果）。だからどんな仮定（前提条件）を置いたかが大切。
  • どんな場面にも使える万能のモデルはない。

経済学の応用

経済理論は、国際経済学、財政学・公共経済学、金融論・ファイナンス、産業組織論、開発経済学などに応用されています。さらに政治学（公共選択論）、歴史（数量経済史）、社会学（結婚や出産の経済学）、法学（法と経済学）、環境問題（環境経済学）にも使われています。

いまの日本の政策課題

景気対策と構造改革、金融政策（デフレからインフレへ）、財政政策、財政赤字と公債残高の増加、少子高齢化と社会保障、地方分権など、どれもマクロ経済学の道具で考えるテーマです。

経済学は、目的に合わせて単純化したモデルで考える。結論を読むときは「どんな仮定を置いたか」を確かめる。

4機会費用と予算制約

ある行動を選ぶと、別の行動はあきらめなければなりません。選ばなかった行動から得られたはずの利益のうち、いちばん大きいものを機会費用（opportunity cost）と呼びます。

メモ：アルバイトと授業時給1,000円のアルバイトを休んで、2時間の講義に出たとする。講義の機会費用は、あきらめたバイト代の2,000円。財布からお金が出ていかなくても、費用はかかっている。

予算制約

2つの財 x（例：パン）と y（例：コーヒー）を買う人を考えます。x の価格を p、y の価格を q、使えるお金（所得）を I とすると、買える組み合わせは次の式を満たします。

px + qy ≤ Iテキスト (1.1)

パンへの支出 ＋ コーヒーへの支出 ≤ 使えるお金

ぴったり使い切る線 px + qy = I を予算線と呼びます。スライダーで価格や所得を変えて、線がどう動くか確かめてください。

x 軸との交点 I/p
y 軸との交点 I/q
傾き（の大きさ）p/q

傾きが機会費用

x をもう1個買うには p 円が必要です。所得は決まっているので、そのぶん y を p/q 個あきらめなければなりません。つまり、予算線の傾き p/q が、x を1個増やす機会費用です。

数値例（p = 2、q = 4、I = 40）
x だけ買うと40 ÷ 2 ＝ 20 個
y だけ買うと40 ÷ 4 ＝ 10 個
x を1個増やす機会費用2 ÷ 4 ＝ y を 0.5 個

価格が2つとも2倍になっても、p/q は変わりません。機会費用を決めるのは価格の比（相対価格）で、価格の水準そのものではありません。

機会費用は「あきらめたものの価値」。予算線の傾き p/q は、x を1個増やすためにあきらめる y の量。

5生産可能性フロンティア

今度は「買う」ではなく「作る」側です。財 x を1個作るのに a 時間、財 y を1個作るのに b 時間かかり、使える時間は全部で L 時間とします。

ax + by ≤ Lテキスト (1.2)

x づくりに使う時間 ＋ y づくりに使う時間 ≤ 使える時間

ぴったり使い切る線 ax + by = L を生産可能性フロンティア（PPF）と呼びます。1時間で作れる量 1/a、1/b は労働生産性です（a や b が小さいほど生産性が高い）。

x を1個多く作るには a 時間が必要で、そのぶん y は a/b 個減ります。PPF の傾き a/b が、x を1個作る機会費用です。この傾きを限界変形率（MRT）と呼びます。

数値例（a = 1 時間、b = 2 時間、L = 24 時間）
x だけ作ると24 ÷ 1 ＝ 24 個
y だけ作ると24 ÷ 2 ＝ 12 個
x を1個増やす機会費用1 ÷ 2 ＝ y を 0.5 個

現実には、x づくりに時間を回すほど、x づくりが苦手な人や設備まで使うことになり、生産性が落ちていくことが多いでしょう。そのときは x を増やすほど機会費用が大きくなり、PPF は外側にふくらんだ曲線になります（切り替えボタンで確かめてください）。

PPF は「作れるものの限界」。その傾き（限界変形率）が、x を1個多く作るためにあきらめる y の量。

6絶対優位と比較優位

AさんとBさんの2人を考えます。数字は説明のための架空の値です。

x を1個作る時間y を1個作る時間使える時間x の機会費用
Aさん1時間2時間24時間1 ÷ 2 ＝ y 0.5個
Bさん6時間3時間30時間6 ÷ 3 ＝ y 2個
  • 絶対優位：Aさんは x も y も、Bさんより短い時間で作れます。Aさんは両方の財に絶対優位を持っています。
  • 比較優位：x の機会費用は、Aさんが y 0.5個、Bさんが y 2個。Aさんは x に、Bさんは y に比較優位を持っています（Bさんにとって y の機会費用は x 0.5個で、Aさんの x 2個より小さい）。
メモ：社長と秘書社長は経営もタイピングも秘書より上手（絶対優位）。それでも、社長は経営に、秘書はタイピングに専念したほうが会社の業績は上がる。大事なのは「どちらが得意か」ではなく「どちらが相対的に得意か」。

1個だけ作る量を入れ替えてみる

Aさんが x を1個多く作り、Bさんが x を1個少なく作るとします。

数値例
Aさん：x を1個増やすy は 0.5 個減る
Bさん：x を1個減らすy は 2 個増える
2人の合計x は同じ、y は ＋1.5 個

2人の機会費用が違うときは、それぞれが比較優位を持つ財の生産を増やすだけで、全体の生産量が増えます。

交換の利益を生むのは絶対優位ではなく比較優位。機会費用が小さい財に、その人は比較優位を持つ。

7特化と交換の利益

それぞれが比較優位を持つ財の生産に専念（特化）し、2人の間で交換すると、2人とも得をします。これを比較優位の原理と呼びます。

自給自足のとき特化して作る交換（x 1個 ＝ y 1個）交換後に消費
Aさんx 20、y 2（点C）x 24（点A）x を3個渡し、y を3個もらうx 21、y 3（点D）両方増える
Bさんx 2、y 6（点E）y 10（点B'）y を3個渡し、x を3個もらうx 3、y 7（点F）両方増える

どんな交換比率なら2人とも得をするか

x 1個と y を何個で交換するか（交換比率 p/q）を動かしてみてください。

Aさんが x を1個売った得
Bさんが x を1個買った得
判定

Aさんの得 ＝ 受け取る y（p/q）− x を作るためにあきらめた y（0.5）。Bさんの得 ＝ 自分で作ったらあきらめる y（2）− 払う y（p/q）。

a₁/b₁ < p/q < a₂/b₂テキスト p.16

交換比率が、2人の機会費用（PPFの傾き）の間にあれば、2人とも得をする

比較優位に従って特化し、2人の機会費用の間の比率で交換すれば、2人とも自給自足より多く消費できる。

8需要と供給：価格が需給をそろえる

縦軸に価格 p、横軸に数量 Q をとります。需要曲線 D は右下がり（安いほどたくさん買われる）、供給曲線 S は右上がり（高いほどたくさん売りに出される）です。

  • 価格が高すぎると、売りたい量が買いたい量を上回り（超過供給）、売れ残りが出て価格が下がる。
  • 価格が低すぎると、買いたい量が売りたい量を上回り（超過需要）、品不足になって価格が上がる。
  • 2本の線が交わる点 E では需要と供給が一致し、価格はもう動かない。これが市場均衡。

価格は、売れ残りがあれば下がり、品不足があれば上がり、需要と供給が一致する点（市場均衡）に落ち着く。

9曲線の高さを読む：限界便益と限界費用

需要曲線と供給曲線は、ふつうは「縦（価格）から横（数量）へ」読みます。逆に「横から縦へ」読むと、消費者や生産者が何を考えているかが見えてきます。

曲線の高さが表すもの呼び名
需要曲線次の1個に、消費者が払ってもよいと思う最高の価格限界便益（marginal benefit）
供給曲線次の1個を、生産者が売ってもよいと思う最低の価格限界費用（marginal cost）
メモ：「限界」は「ぎりぎり」ではない経済学の「限界（marginal）」は、「もう1個増やしたら」という意味。「我慢の限界」の限界とは違う。限界便益は「もう1個買うと増える満足」、限界費用は「もう1個作ると増える費用」。

生産者は、次の1個を売って得られる収入（競争的な市場では価格 p）が、その1個を作る費用（限界費用 MC）以上なら作ります（p ≥ MC）。だから、供給曲線の高さは限界費用に等しくなります。

需要曲線の高さ＝限界便益、供給曲線の高さ＝限界費用。曲線を「横から縦へ」読むと、人々の意思決定が見える。

消費者余剰と生産者余剰

1個ずつの取引で考えます。価格は5円で、消費者が払ってもよい価格と、生産者の限界費用は次のとおりです（架空の値）。

  • 生産者余剰（PS）＝ 収入 − 限界費用の合計（可変費用）＝ 4 + 3 + 2 + 1 ＝ 10（固定費用は含めない）

SS = CS + PS = 総便益 − 生産費用

支払いと収入は打ち消し合うので、社会的余剰は「満足の合計 − 作るのにかかった費用」になる

  • 均衡より少ない量（Q₁）では、限界便益 > 限界費用。量を増やすと社会的余剰が増える。
  • 均衡より多い量（Q₂）では、限界便益 < 限界費用。量を減らすと社会的余剰が増える。
  • 限界便益 ＝ 限界費用 となる市場均衡 E で、社会的余剰は最大になる。

なお、社会的余剰は「効率」を測る物差しで、「公平」（所得の分け方）については何も言っていない点に注意しましょう。

市場均衡では限界便益と限界費用が等しく、社会的余剰（CS＋PS）が最大になる。この意味で市場均衡は望ましい。

11市場の失敗

市場均衡が社会的余剰を最大にするのは「ふつうの場合」です。市場がうまく働かないケースを市場の失敗と呼び、代表例は次の4つです。

ケースどういうことか例
公共財一度供給されると多くの人が同時に恩恵を受けられ（非競合性）、お金を払った人だけに限定できない（排除不可能性）。市場では供給できず、政府の役割になる国防、警察
外部性取引の当事者以外に影響が漏れる。生産者が被害の費用を考えずに生産するので、望ましい生産量にならない工場の排水による川の汚染
競争条件の阻害独占企業が、わざと量を絞って利益を大きくする独占市場
情報上の失敗売り手と買い手で、品質について知っている情報に差がある中古車の品質

古典派とケインズ派の違いも、「市場がどこまで理想的に働くか」の判断の違いでした。市場の働きを理解することは、マクロ経済学でも欠かせません。

公共財・外部性・独占・情報の偏りがあると、市場に任せても社会的余剰は最大にならない（市場の失敗）。

12制約付きの最適化と、関数の傾き

数学は経済学者どうしの共通言語であり、道具です。大事なのは難しい計算よりも、式やグラフから経済的な意味を読み取ることです。

制約条件付き最適化

現代の経済学では、多くの問題を「制約のもとで、何かをいちばん大きくする」問題として考えます。消費者なら、予算の範囲で満足（効用）をいちばん大きくします。

max U(x, y)   s.t. px + qy ≤ I

予算 px + qy ≤ I を守りながら（s.t. ＝ 〜という条件のもとで）、効用 U をいちばん大きくする

いちばん大きくしたいもの（効用関数）を目的関数、守らなければならない式（予算制約）を制約条件と呼びます。予算線の描き方は 第4節 で確かめました。

関数と傾き

C = C(Y) のように書くと、「消費 C は所得 Y で決まる（Y の関数）」という意味です。具体的な形を決めたものの例が、ケインズ型消費関数です。

C = c₀ + c₁Y　（0 < c₁ < 1）

消費 ＝ 所得がゼロでも必要な消費 ＋ 所得のうち消費に回す割合 × 所得

  • 切片 c₀ ＝ 基礎消費：所得がゼロでも生きるために必要な消費。
  • 傾き c₁ ＝ 限界消費性向：所得が1円増えたときに増える消費。「もう1円増えたら」なので「限界」と呼ぶ。

式からグラフの形が描けること、係数の意味が分かること、グラフから式が書けることの3つを目標にしましょう。

経済学の基本は「制約のもとでの最適化」。直線の式では、切片と傾きがそれぞれ経済的な意味を持つ。

13限界概念と微分

限界効用、限界消費性向、限界費用など、経済学には「限界」がたくさん出てきます。どれも少し増やしたら結果がどれだけ変わるかを表し、数学では「傾き」や「微分」に当たります。

ΔUΔx　→　limΔx→0ΔUΔx = U′(x)

14無限等比級数の和と乗数

マクロ経済学では、あるショックが次々に波及していく効果（乗数）を計算します。例えば政府支出を増やすと、GDP は何倍に増えるでしょうか。

Y = C + I + G　①　　C = a + bY　②

①需要と供給が等しい　②消費は所得で決まる（b は限界消費性向）

政府支出を ΔG 増やすと、①より Y が ΔG 増える → ②より C が bΔG 増える → ①より Y が bΔG 増える → ②より C が b²ΔG 増える…と、波及が永遠に続きます。

ΔY = (1 + b + b2 + b3 + ⋯)ΔG = 11 − bΔG

波及の合計は無限等比級数。初項1、公比 b の和は 1/(1 − b)

乗数 1/(1−b)
ΔG = 1 のとき ΔY

棒は各回の増加（1, b, b², …）、折れ線はそこまでの合計。合計は 1/(1−b) に近づいていく。

15総和記号 Σ と総積記号 Π

たくさんの項を足したり掛けたりする式は、記号でまとめて書きます。

nΣi=1Xi = X1 + X2 + ⋯ + Xn総和（シグマ）
nΠi=1Xi = X1 × X2 × ⋯ × Xn総積（パイ）

下の「i = 1」から上の「n」まで、i を1ずつ増やしながら、右の式に i を入れて足す（Σ）、または掛ける（Π）

メモ：Σ は「くり返しの指示書」「i を1から順に入れて、出てきたものを全部足しなさい」という命令文だと思えばよい。i はくり返しのたびに変わる番号で、最後には式から消える。

書き下してみよう

よく使う性質

  • 定数は Σ の外に出せる：Σ cXi ＝ c Σ Xi
  • 番号の文字は何でもよい：Σi=1 Xi と Σt=1 Xt は同じ
  • Π で同じものを n 回掛けると累乗：Πi=1n c ＝ cⁿ

Σ と Π は 課題 演習(1) で使います

Σ は「番号を変えながら足す」、Π は「番号を変えながら掛ける」。下が始まり、上が終わりの番号。

16微分と積分の関係、積分は面積

23演習(2)の(2)：積分を図示する

問題

(2) 1∫0x dx を図示せよ。

ヒント定積分は「グラフと x 軸に挟まれた部分の面積」でした。まず y = x のグラフを描き、x = 0 から x = 1 までの範囲に色を塗りましょう。どんな図形になるでしょうか。

復習：パート4「積分は面積」

解説と答案例は、まだ公開されていません。

手順1積分の中身のグラフを描く

∫ の中身は x なので、y = x のグラフ（原点を通る傾き1の直線）を描きます。

手順2範囲を決めて塗る

∫ の下の 0 と上の 1 が範囲です。x = 0 から x = 1 まで、直線 y = x と x 軸に挟まれた部分を塗ります。

答案にグラフを描くときの手順

  1. 横軸に x、縦軸に y と書き、原点 O を書く。
  2. 原点を通る傾き1の直線を描き、「y = x」と書き込む。
  3. x = 1 に縦の点線を引き、直線との交点 (1, 1) に印を付ける。
  4. 原点、(1, 0)、(1, 1) を頂点とする三角形に斜線を引き、「∫₀¹ x dx」と書く。

手順3面積を計算して確かめる

塗った部分は、底辺1、高さ1の直角三角形です。面積は 1 × 1 ÷ 2 ＝ 1/2。原始関数を使って計算しても同じになります。

1∫0x dx = [x22]01 = 12 − 0 = 12

x²/2 を微分すると x に戻る（x²/2 は x の原始関数）

手順4結論

よくある間違い　直線だけ描いて範囲を塗らない（問われているのは面積）。範囲を x = 0〜1 ではなく y = 0〜1 として塗ってしまう。

y = x と x 軸、x = 1 で囲まれた三角形の面積として図示できる。面積は 1/2。

∫₀¹ x dx は、直線 y = x と x 軸、および直線 x = 1 で囲まれた部分の面積を表す。これは原点 O、点 (1, 0)、点 (1, 1) を頂点とする直角三角形であり、図のように斜線で示される。

その面積は底辺1、高さ1より 1 × 1 ÷ 2 = 1/2 である（原始関数 x²/2 を用いても [x²/2]₀¹ = 1/2 となり一致する）。
