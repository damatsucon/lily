1第4章で何が変わるか

この章も、第3章と同じ古典派のモデル（市場がうまく働き、完全雇用が成り立つ）を使います。変えるのは2点です。

第3章（基本モデル）第4章（拡張モデル）
消費を決めるもの今の可処分所得 C = C(Y − T)恒常所得 C = C(Yᴾ)、さらに利子率 C = C(Yᴾ, r)
財の供給完全雇用の Ȳ で一定（垂直）利子率が上がると今もっと働く Yˢ = Yˢ(r)（右上がり）
考える時間1時点だけ（静学モデル）今と将来のつながり（動学モデル）

この拡張によって、その変化が「一時的」か「恒常的（ずっと続く）」かで、結果が大きく変わるようになります。これがこの章のいちばん大事な点です。

第4章は、第3章のモデルに「将来の見通し」を入れたもの。変化が一時的か恒常的かを区別することが重要になる。

2恒常所得と変動所得

ある年の所得は、長い目で見た平均的な部分（恒常所得）と、その年だけの上下（変動所得）に分けられます。

Y = Yᴾ + Yᵀスライド p.4

所得 ＝ 恒常所得（permanent income）＋ 変動所得（transitory income）

C = C(Yᴾ)テキスト (4.1)

消費は恒常所得だけで決まる。一時的な所得の上下には反応しない

これを恒常所得仮説と呼びます。家計は将来の所得まで見通して、毎期なるべく同じ水準の消費を続けようとします。一定の条件のもとでは、毎期の消費は生涯所得の平均に等しくなります。

C1 = C2 = ⋯ = CT = Σt=1T YtT ≡ YPスライド p.5

各期の消費 ＝ T 期間の所得の平均 ＝ 恒常所得（利子がゼロの単純な場合）

所得が変動しても消費を一定にできるのは、貯蓄がクッションになるからです。所得が平均より多い期は貯蓄し、少ない期は貯蓄を取り崩します（St = Yt − Yᴾ）。

メモ：宝くじと昇進宝くじで10万円当たった人は、たいてい生活の水準そのものは変えません（変動所得）。一方、昇進して給料がずっと上がることが決まった人は、外食や住まいを少しずつ良くしていくでしょう（恒常所得）。同じ「収入が増えた」でも、消費への影響はまったく違います。

恒常所得仮説については、第11章でさらにくわしく学びます。この章では、話を簡単にするため、恒常所得が1増えると消費もちょうど1増える（恒常所得からの消費性向は1）と考えます。

消費は恒常所得 Yᴾ で決まる。一時的な所得の変化は貯蓄で吸収され、消費はほとんど動かない。恒常的な変化だけが消費を動かす。

3財市場と貸付資金市場：どの線が動くか

第3章と同じく、財市場の均衡を考えます。違うのは、需要の中の消費が恒常所得で決まることだけです。

Yᵈ = C(Yᴾ) + I(r) + Gテキスト (4.2)

財の需要 ＝ 恒常所得で決まる消費 ＋ 利子率で決まる投資 ＋ 政府支出

S ≡ Y − C(Yᴾ) − Gテキスト (4.3)

国民貯蓄は、今の所得 Y と恒常所得 Yᴾ の両方で決まる

大事なのは、Yˢ の線を動かすのは今の Y、Yᵈ の線を動かすのは恒常所得 Yᴾという点です。今の所得と恒常所得の変わり方の組み合わせで、どの線が動くかが決まります。

変化今の Y恒常所得 Yᴾ動く線
一時的な産出量の増加増える変わらないYˢ だけ右へ
恒常的な産出量の増加（今から）増える同じだけ増えるYˢ も Yᵈ も右へ
恒常的な産出量の増加（将来から）変わらない増えるYᵈ だけ右へ
この解説で使う数値例（説明のための架空の値。第2・第3パートで使います）
今の生産 Y ＝ 恒常所得 Yᴾ、政府支出 G ＝ 税 T500、80
消費 C ＝ (Yᴾ − T) − 40（恒常所得が1増えると消費も1増える）380
投資 I ＝ 80 − 10rr ＝ 4% で 40
需要 Yᵈ ＝ 380 ＋ (80 − 10r) ＋ 80 ＝ 540 − 10r、供給 Yˢ ＝ 500r ＝ 4%
国民貯蓄 S ＝ 500 − 380 − 8040（＝ I）

Yˢ を動かすのは今の所得、Yᵈ（と消費）を動かすのは恒常所得。貯蓄 S ＝ Y − C(Yᴾ) − G は両方に左右される。

4一時的な産出量の増加：利子率が下がる

天候に恵まれて今年だけ豊作になった、という場合です。今の生産 Y は増えますが、恒常所得は変わりません。数値例で、今年だけ生産が20増えるとします。

増えた所得は消費に回らず、まるごと貯蓄になります。貸したいお金が増えるので利子率が下がり、投資が増えます。新しい均衡では、利子率の低下、貯蓄と投資の増加が起きています。

供給曲線が右上がりの場合は 課題① で考えます

一時的な産出量の増加：Yˢ だけが右へ。C 不変、S と I が増え、r が下がる。

5恒常的な産出量の増加：利子率は変わらない

画期的な技術が実用化され、今年から生産がずっと20増える場合です。今の Y も恒常所得 Yᴾ も20増えます。

消費性向を1としているので、消費も20増えます。供給と需要が同じだけ増えるので、利子率は変わらず、貯蓄も投資も変わりません。増えた生産は、すべて消費に回ります。

恒常的な産出量の増加（今から）：Yˢ と Yᵈ が同じだけ右へ。r・S・I は不変、C が Y と同じだけ増える。

6恒常的な増加が将来起こる場合：利子率が上がる

新しい技術が発見されたが、実用化までに時間がかかる場合です。今の生産は変わりませんが、将来の所得が増えることがわかったので、今の恒常所得が増えます。

家計は将来の所得をあてにして、今から消費を増やします。今の生産は増えていないので、利子率が上がり、投資が減ります。実際に生産が増えた時点では、第5節と同じ状態になり、貯蓄の線も元に戻ります。

恒常的な増加が将来起こる：今は Yᵈ だけが右へ。C が増え、S と I が減り、r が上がる。

7資本の限界生産物の増加：投資と消費の両方が増えようとする

機械の性能が上がるなどして、資本の限界生産物 MPK が上がった場合です。企業にとって最適な資本の量（MPK ＝ r となる K）が増えるので、どの利子率でも投資が増えます（投資関数が右へ）。さらに、投資で将来の生産が増えるので恒常所得も増え、消費も増えます。

今の生産は増えないので、結論は「今の均衡生産量は変わらず、利子率が上がる」です。第6節と比べると、投資の増加も加わるので、需要の線の動きはより大きくなります。

注意したいのは、新しい均衡での投資です。今の生産は増えず消費が増えるので、貯蓄 S ＝ Y − C − G は減ります。S ＝ I なので、均衡の投資は増えるどころか減ります（数値例では 40 → 30）。「投資を増やそうとする力」は、利子率の上昇でおさえこまれるのです。

MPK の上昇：I(r) が右へ、Yᴾ の増加で C も増える。今の Y は不変、r が上がる。均衡の投資は貯蓄の減少分だけ減る。

8「一時的」と「恒常的」の意味

政府が今お金を使えば、いつかは税で払わなければなりません（国債で借りても、返すのは将来の税です）。そこで、家計の税負担の合計（将来の税は割り引いて今の価値に直す）が変わるかどうかで区別します。この章の恒常所得は、すべて税引き後の恒常所得です。

政策意味恒常所得
一時的な政府支出の増加1回限り。将来どこかで同じ額（割引価値）だけ支出を減らす変わらない
恒常的な政府支出の増加今から将来までずっと増やす。税負担もずっと重くなる増加分だけ減る
一時的な減税今の減税を将来の増税で埋め合わせる変わらない
恒常的な減税ずっと減税する。そのためには政府支出もずっと減らす必要がある減税分だけ増える
メモ：家計のやりくりと同じ親から「今月だけお小遣いを1万円増やすけど、来月は1万円減らすね」と言われたら、使い方はあまり変えないでしょう。「これからずっと1万円増やす」なら、生活を変えます。政府の政策も、家計から見ると同じように受け止められるのです。

一時的な政策は家計の生涯の税負担を変えず、恒常所得も変えない。恒常的な政策は恒常所得を変える。

9政府支出の増加：一時的と恒常的

数値例で、G を80から100に20増やします。

一時的な増加は、第3章と同じように投資を押しのけます（クラウディング・アウト）。財源を税にしても国債にしても、結果は同じです。一方、恒常的な増加は、同じ額だけ消費を減らすだけで、利子率も投資も変わりません。

メモ：政府支出の中身も大事政府支出がインフラ整備のように生産を増やすものなら、将来の生産を増やす効果も考える必要があります。それは第11節の公共投資で扱います。

供給曲線が右上がりの場合は 課題② で考えます

一時的な G の増加：C 不変、I が減り r が上がる。恒常的な G の増加：C が同額減り、Yᵈ は動かず r・I は不変。

10減税とリカードの等価定理

税 T を20減らします。

一時的な減税20のとき、貯蓄の中身はこう変わる（架空の値）
民間貯蓄 SP ＝ Y − T − C：500 − 60 − 38060（＋20）
政府貯蓄 SG ＝ T − G：60 − 80−20（−20）
国民貯蓄 S40（変わらない）

一時的な減税は、経済に何の影響も与えません。これをリカードの等価定理と呼びます。政府支出の流れが決まっていれば、その財源を今の税で賄っても、国債（＝将来の税）で賄っても同じという命題です。家計は将来の増税に備えて、減税分を貯蓄に回します。

メモ：等価定理が成り立たないとき減税から増税までの間に世代が入れかわると、減税の恩恵だけを受けて退出する世代が消費を増やすかもしれません。将来世代のことを考えない場合、リカードの等価定理は厳密には成り立たなくなります。

恒常的な減税は消費を増やしますが、政府支出を同じだけ減らす必要があるので、需要の合計は変わりません。中身が G から C に入れ替わるだけです。

供給曲線が右上がりの場合は 課題③ で考えます

一時的な減税：何も変わらない（リカードの等価定理）。恒常的な減税：C が増え G が減るだけで、Y も r も変わらない。

11公共投資：有益か無駄か

道路や港の整備などの公共投資は、将来の生産を増やすかもしれません。1単位の公共投資が、将来の生産を毎年 ρ（ロー）増やし、その費用として毎年 r（利子率）の税負担がかかるとします。公共投資を ΔG 増やすと、家計の恒常所得は (ρ − r)ΔG だけ変わります。

ΔYᵈ = ΔC + ΔG = (1 + ρ − r)ΔGテキスト p.100

実施した期の需要の増加 ＝ 恒常所得の変化による消費の変化 ＋ 公共投資そのもの

  • 有益な公共投資（ρ > r）：税負担以上に生産を増やす。恒常所得が増え、将来は生産能力の増加で利子率が下がる。
  • 無駄な公共投資（ρ < r）：費用に見合う効果がない。恒常所得が減り、消費が減る。生活基盤のインフラ（下水道など）のように GDP に表れにくい効果もあるが、そうした効果も小さい場合や、民間でもできる投資を置きかえただけの場合が無駄にあたる。
メモ：この分析の限界実施した期の利子率の上昇は民間投資を減らし、将来の資本を減らすかもしれません。この効果まで含めるには、もっと本格的な動学モデルが必要で、上級の教科書で扱われます。

公共投資の効果は ρ と r の大小で決まる。ρ > r なら恒常所得が増え、ρ < r なら減る。

12利子率は「今」と「将来」の値段の比

利子率が10%なら、今日の10,000円は来年11,000円になります。逆に言えば、来年の10,000円は、今の価値では10,000円より少ないのです。

来年の 10,000 円の今の価値 ＝ 10,0001 + 0.1 ≒ 9,091 円スライド p.17

将来のお金を利子率で割り引いた値を割引現在価値と呼ぶ

今のモノの値段を1とすると、1年後のモノの値段は 1/(1 + r) です。利子率が上がると、将来のモノが相対的に安くなり、今のモノが相対的に高くなります。これが、この部分のすべての議論の出発点です。

現在財の価格を1とすると、将来財の価格は 1/(1 + r)。利子率の上昇は、今の消費（今の余暇）を相対的に高くする。

132期間モデルと生涯の予算制約

人生を「若いとき（第1期）」と「年をとってから（第2期）」の2期間で考えます。第1期の賃金 W1 の一部を消費 C1 にあて、残りを貯蓄 S します。第2期は、その元利合計と賃金 W2 をすべて使い切ります。

C₁ + S = W₁　　C₂ = (1 + r)S + W₂テキスト (4.4)(4.5)

第1期の予算制約と第2期の予算制約

2つの式から S を消すと、生涯の予算制約が得られます。

C1 + C21 + r = W1 + W21 + rテキスト (4.6)

消費の割引現在価値の合計 ＝ 賃金の割引現在価値の合計（生涯賃金）

毎期同じだけ消費する（C1 = C2）なら、その水準が恒常所得 Yᴾ です。下の図で、利子率を動かしてみてください。

生涯賃金 W₁ + W₂/(1+r)
恒常所得 Yᴾ（C₁ = C₂）
第1期の貯蓄 W₁ − Yᴾ

架空の例：W₁ = 100、W₂ = 110。予算線は賃金の組 F（100, 110）を必ず通り、傾きは (1 + r)。利子率が上がると、F を中心に時計回りに回って急になります。

メモ：将来の給料を担保に借りるW2/(1 + r) は、第2期の給料 W2 をあてにして、第1期に借りられる金額です。借りた額 x に利子をつけて返すと x(1 + r) = W2 になるからです。生涯賃金は「人生の初めに給料を全部まとめてもらったら、いくらか」を表しています。

生涯の予算制約：C₁ + C₂/(1 + r) = W₁ + W₂/(1 + r)。毎期同じ消費を続けるときの水準が恒常所得。

14消費も利子率に反応する：C = C(Yᴾ, r)

利子率が上がると、今の消費が相対的に高くなります。だから、恒常所得が同じでも、今の消費を減らして貯蓄を増やし、将来の消費を増やそうとします。消費関数は利子率の減少関数になります。

C = C(Yᴾ, r)　　Yᵈ = C(Yᴾ, r) + I(r) + Gテキスト p.103

利子率が下がると、投資だけでなく消費も増える。需要曲線は右下がりのまま

所得効果と代替効果

正確には、価格の変化には2つの効果があります。ミクロ経済学の「リンゴとミカン」と同じ考え方です。

効果意味利子率が上がったとき、今の消費は
代替効果相対的に安くなったものに需要が移る減る（将来の消費の方が安い）
所得効果実質的な所得が変わる効果増えることもある（貯蓄する人には利子収入が増える）

最終的な効果は2つの大小で決まりますが、テキストは基本的に代替効果が大きいとして説明しています（スライド p.19）。

貯蓄は S = Y − C(Yᴾ, r) − G なので、利子率が上がると消費が減って貯蓄が増えます。貸付資金市場の貯蓄の線は右上がりになります。

利子率の上昇は今の消費を割高にする（代替効果）。C = C(Yᴾ, r) は r の減少関数で、貯蓄の線は右上がりになる。

15労働の異時点間代替：供給曲線が右上がりになる

働くか休むか（余暇）の選択にも、同じ考え方が使えます。余暇の費用は、その時間働いていれば得られた賃金です。利子率が上がると、将来の余暇の費用（割引現在価値 w/(1 + r)）が下がり、今の余暇が相対的に高くなります。

  1. 利子率が上がる → 今休むのは割高、将来休む方が割安。
  2. 今もっと働き、将来はその分休む（労働供給の異時点間代替）。
  3. 今の労働が増えるので、今の生産が増える → Yˢ = Yˢ(r) は r の増加関数（右上がり）。
メモ：働くなら今か、来年か今年の残業代を貯金すると、利子がつきます。利子率が高いほど「今年がんばって働いて貯め、来年はゆっくりする」方が得になります。夏休みにアルバイトを増やして、学期中は勉強に集中する学生の選び方と似ています。

供給曲線の形で、結果が変わる

スライド p.22 の例で、一時的に政府支出を15増やしたときを比べます（数値は架空の値。課題と同じモデル）。

供給が右上がりなら、需要が増えたとき、利子率の上昇に加えて生産も増えます。古典派モデルでも、短い期間に生産量が動くようになるのです。一見ケインズ的なしくみに見えますが、生産が増えるのは「利子率が上がって今働く方が得になるから」で、ケインズのモデルとはまったく違う理由です。

労働の異時点間代替で Yˢ(r) は右上がり。需要の増加は、利子率の上昇と生産の増加の両方で吸収される。

  • 消費と労働の異時点間代替を考えると、需要は右下がり、供給は右上がりになり、需要の変化が生産量も動かす。

17確認問題

テキストの復習問題（p.109–110）をもとにしています。答えを考えてから「解答を見る」を押してください。

Q1（復習問題1）第3章の消費関数 C = C(Y − T) と、この章の C = C(Yᴾ) の違いは？
第3章は今の可処分所得で消費が決まり、所得が一時的に増えても消費が増える。この章は税引き後の恒常所得（長期の平均的な所得）で決まり、一時的な所得の変化には反応しない。
Q2（復習問題2・3）一時的な産出量の増加と、恒常的な産出量の増加（今から）では、利子率はどう違うか。
一時的な増加では消費が増えず、増えた所得は貯蓄になるので利子率が下がる。恒常的な増加では消費も同じだけ増え、貯蓄は変わらないので、利子率は変わらない。
Q3（復習問題5）リカードの等価定理とは何か。
政府支出の流れが決まっていれば、その財源を税で賄っても国債で賄っても経済への効果は同じ、という命題。一時的な減税は将来の増税で埋め合わされるので恒常所得を変えず、財市場に何の影響も与えない。
Q4（復習問題6）1単位の公共投資が生産を毎年 ρ 増やし、税負担が毎年 r かかる。ρ と r の大小で何が違う？
ρ > r なら恒常所得が (ρ − r)ΔG 増えて消費が増え、将来は生産能力が増える（有益な公共投資）。ρ < r なら恒常所得が減り、消費が減る（無駄な公共投資）。
Q5（復習問題7）利子率が5%のとき、1年後の1万円は今のいくらに相当するか。
10,000 ÷ 1.05 ≒ 9,524円。今の9,524円を5%で預けると、1年後に約1万円になるから。
Q6（復習問題8）C₁ + S = W₁ と C₂ = (1 + r)S + W₂ から、生涯の予算制約を求めよ。
第2期の式を (1 + r) で割ると C₂/(1 + r) = S + W₂/(1 + r)。これを第1期の式に足して S を消すと、C₁ + C₂/(1 + r) = W₁ + W₂/(1 + r)。

供給曲線が右上がりの時、一時的な産出量増と恒常的な産出量増で、財市場にどんな変化が起こるか。グラフで描き、簡単にコメントせよ。

手順4結論

よくある間違い　一時的な産出量増で「所得が増えるので消費も増え、Yᵈ も右へ動く」と描くこと。消費は恒常所得で決まるので、一時的な所得の増加では消費は（ほとんど）増えません。

一時的な産出量増：Yˢ だけが右へ。r は下がり、Y は増えるが、増え方は垂直の場合より小さい。恒常的な産出量増：Yˢ も Yᵈ も同じだけ右へ。r は変わらず、Y は生産能力の増加分だけ増える。

一時的な産出量の増加では、どの利子率のもとでも今の生産が増えるので供給曲線 Yˢ が右にシフトする。一方、恒常所得は変化しないので消費は変わらず、需要曲線 Yᵈ はシフトしない。当初の利子率では超過供給となるため利子率が低下し、新しい均衡では利子率が下がり、産出量は増加する。ただし供給曲線が右上がりなので、利子率の低下によって現在の労働供給がいくらか減り、産出量の増加は供給曲線のシフト幅より小さい（垂直な場合より小さい）。

恒常的な産出量の増加では、供給曲線 Yˢ が右にシフトするとともに、恒常所得が同額だけ増えて消費も増えるため、需要曲線 Yᵈ も同じ幅だけ右にシフトする。そのため均衡利子率は変化せず、産出量はシフト幅の分だけ増加する。この結果は供給曲線が垂直な場合と同じである。

20課題②：恒常的な政府支出増加

問題

供給曲線が右上がりの時、恒常的な政府支出増加で、財市場にどんな変化が起こるか。グラフで描き、簡単にコメントせよ。

ヒントG が増えると需要は増えます。しかし「恒常的」な増加では、将来ずっと税が増えます。家計の恒常所得はどうなり、消費はどう変わるでしょうか。スライド p.22 の一時的な増加の図と比べてみましょう。

数値例（架空の値）

一時的な増加では、利子率が上がり、供給曲線に沿って生産も増えました（スライド p.22 の右の図）。恒常的な増加では需要曲線が動かないので、供給曲線が右上がりかどうかに関係なく、利子率も生産も変わりません。

手順4結論

よくある間違い　スライド p.22 の図（一時的な増加）と同じように Yᵈ を右へ動かしてしまうこと。恒常的な増加では、増税を見込んだ消費の減少が G の増加を打ち消します。

Yᵈ も Yˢ も動かず、r も Y も変わらない。G の増加と同じだけ C が減り、需要の中身が入れ替わるだけ。

政府支出が恒常的に増加すると、家計は将来にわたる税負担の増加を予想するので、税引き後の恒常所得が政府支出の増加分だけ減少し、消費も同額だけ減少する（恒常所得からの消費性向を1とする）。需要 Yᵈ ＝ C(Yᴾ, r) ＋ I(r) ＋ G のうち G の増加と C の減少が打ち消し合うため、需要曲線はシフトしない。供給曲線もシフトしない。

したがって、供給曲線が右上がりであっても、均衡の利子率と産出量は変化せず、投資も変わらない。変わるのは需要の構成（消費が減って政府支出が増える）だけである。一時的な政府支出の増加では需要曲線が右にシフトし、利子率の上昇とともに供給曲線に沿って産出量が増加したのとは対照的である。

よくある間違い　「減税で手取りが増えるので消費が増え、Yᵈ が右へ動き、右上がりの供給曲線に沿って生産が増える」と描くこと。第3章のモデル（消費が今の手取りで決まる）なら Yᵈ は動きますが、この章のモデルでは、一時的な減税は恒常所得を変えません。

一時的な減税：Yᵈ も Yˢ も動かず、経済に何の影響もない（リカードの等価定理）。恒常的な減税：C の増加と G の削減が打ち消し合い、r も Y も変わらない。需要の中身が G から C に移るだけ。

一時的な減税は将来の増税によって埋め合わされるため、家計の税引き後の恒常所得を変化させない。したがって消費は変わらず、需要曲線はシフトしない。供給曲線もシフトしないので、供給曲線が右上がりであっても利子率と産出量は変化しない。家計は減税分を貯蓄し、民間貯蓄の増加が政府貯蓄の減少を打ち消す（リカードの等価定理）。

恒常的な減税は、政府支出の恒常的な削減を伴ってはじめて可能である。減税によって恒常所得が増え消費が増加するが、同額の政府支出が削減されるため、需要曲線はシフトしない。したがって利子率と産出量は変化せず、需要の構成が政府支出から消費へ入れ替わるだけである。ただし、削減される政府支出がインフラ投資など生産力を高めるものであれば長期的に産出量は減り、無駄な支出であれば長期的に産出量は増える可能性がある。
