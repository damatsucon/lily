1閉じた経済と、開いた経済

第4章までのモデルは、外国との取引を考えない閉鎖経済でした。この章では、外国とつながった開放経済を考えます。

メモ：村で考えてみよう 島で自給自足している村では、作ったお米は村の中で食べるか、来年の種もみにするしかない。つまり「作った量＝使った量」。
港のある村なら、足りなければ外国から買えるし（輸入）、余れば売れる（輸出）。お金が足りなければ借りられるし、余れば貸せる。

このように開放経済では、「作った量」と「使った量」がずれてもよくなります。ただし、借りたお金はいつか返さなければなりません。このずれと、返済のルールを調べるのが第5章です。

開放経済では「作った量」と「使った量」がずれてよい。ずれは外国との売り買い・貸し借りで埋まる。

3作った量と使った量（式その1）

自国で作ったモノを買うのは、国内の人と外国の人です。

  • 国内の人の支出は C+I+G。ただし一部は外国製品に回るので、輸入 IM を差し引く。
  • 外国の人が買う分が輸出 EX。

作った量 Y がちょうど売れ切れる状態（均衡）では、次の式が成り立ちます。

Y = C + I + G + (EX − IM) = A + NXテキスト (5.3)(5.5)

作った量 ＝ 国内で使った量 ＋ 純輸出

移項すると NX = Y − A。

下の帯グラフで「黒字の例」と「赤字の例」を切り替えて、2本の帯の長さを比べてみよう。
作った量 Y
使った量 A

  • 作った量 > 使った量なら、余りを外国に売るので貿易黒字
  • 作った量 < 使った量なら、不足を外国から買うので貿易赤字

貿易黒字を「輸出を頑張ったから」と考えるのではなく、国内で作った量と使った量の差として考えます。この見方をアブソープション・アプローチと呼びます。

貿易収支 ＝ 作った量 − 国内で使った量。使いすぎれば赤字、使い残せば黒字。

4対外純資産と経常収支（式その2）

貿易黒字の国は売った代金を受け取り、そのお金を外国に貸したり、外国の資産を買ったりします。こうして積み上がる外国への「貯金」が対外純資産 B です（外国に貸している額 − 外国から借りている額）。

メモ：貯金箱で考えよう来年の残高 ＝ 今年の残高 ＋ 利息 ＋ 今年入れた分。入れた分が「貿易黒字」に当たる。
B+1 = (1 + r)B + NXテキスト (5.6)

来年はじめの残高 ＝ 今年はじめの残高と利息 ＋ 今年の貿易黒字

1年間での残高の増え方を経常収支 CA と呼びます。

CA = B+1 − B = rB + NXテキスト (5.8)

貿易収支と経常収支は別物です。貿易収支はモノの売り買いの差、経常収支はそれに外国からの利息の受け取りを加えたものです。

GDPとGNI

Y（GDP）は「国内で作った量」、Y + rB は外国から受け取る利息まで含めた「国民の所得」で、GNI（国民総所得）に当たります。式その2は「経常収支 ＝ GNI − 国内で使った量」とも読めます。

メモ：現実の日本では近年の日本は、貿易収支が赤字になる年がある一方、海外への投資から受け取る利子・配当が大きく、経常収支は黒字が続いている。rB が大きく、NX を補っている状態。

経常収支は「外国への貯金が1年でいくら増えたか」。中身は利息の受け取りと貿易黒字。

単位：兆円。投資に使い切れなかった20を外国に貸している（経常収支黒字）。逆に S < I なら、足りない分を外国から借りて投資している（経常収支赤字）。

言い換えると、経常収支は貯蓄と投資の差額（CA = S − I）です。閉鎖経済では外国に貸せないので S = I でした。開放経済ではこの等式が S = I + CA に広がった、と考えると分かりやすいでしょう。

式の導き方（興味のある人向け）

式その2より CA = rB + Y − A = rB + Y − C − I − G。ここで S = rB + Y − C − G なので CA = S − I。I を移項して S = I + CA。代入と移項だけで導けます。

国の貯蓄は「国内投資」か「外国への貸し付け」に回る。経常収支 ＝ 貯蓄 − 投資。

6利子率と国内需要（グラフの準備）

このあとのグラフは、縦軸が利子率 r、横軸がモノの量です。経済学では価格（ここでは利子率）を縦軸にとるのが慣例です。

国内で使う量 A は、利子率が上がると減る

  • 投資 I：金利が上がると、借金して工場を建てるのが割に合わなくなるので減る。
  • 消費 C：金利が上がると、今使わずに貯金したほうが得になるので減る。

このため A = C(YP, r) + I(r) + G のグラフは右下がりになります。C(YP, r) は「消費は恒常所得と利子率で決まる」という意味です。

作る量 Yˢ は、利子率と関係なく決まる

第4章の古典派モデルでは、働く人と機械がすべて使われる（完全雇用の）水準で生産量が決まります。利子率が変わっても作れる量は変わらないので、Ys のグラフは垂直な線になります。

使う量 A は右下がり、作る量 Yˢ は垂直線。

7世界利子率と小国の仮定

ある国の輸出は、必ずどこかの国の輸入です。だから世界の純輸出を全部足すとゼロになり（NX + NX* = 0）、世界全体では「作った量＝使った量」が成り立ちます。

Y + Y* = A + A*テキスト (5.11)

世界で作った量 ＝ 世界で使った量

この等式が成り立つように決まる利子率が世界利子率 r₀ です。お金は国境を越えて自由に貸し借りできるので、どの国でも同じ利子率になります。

お金の面から見ても同じです。世界全体の貯蓄と投資が等しくなるように（S + S* = I + I*）世界利子率が決まります。財の面から見ても、お金の面から見ても、同じ r₀ にたどり着きます。

小国の仮定

自国が世界に比べて十分に小さく、自国で何が起きても世界利子率は動かない、と考えるのが小国の仮定です。自国は世界利子率を「与えられたもの」として受け入れるだけです。自国の出来事が世界利子率まで動かすほど大きい国は大国と呼びます。以下では小国を前提にします。

メモ：預金者と銀行金利一人の預金者がいくら預金を増やしても、銀行の金利は変わらない。小国と世界利子率の関係はこれと同じ。

世界利子率は世界全体の需給で決まる。小国にとっては動かせない「外から与えられた値」。

グラフの読み方は3ステップです。

  1. 世界利子率 r₀ の高さに横線を引く。

  3. 二つの点の横の距離が純輸出。Yˢ が右にあれば黒字、A が右にあれば赤字。

「A線の位置」は、利子率が0%のときに国内で使う量です。消費・投資・政府支出のどれかが増えると右へ動きます。

純輸出は「r₀ の高さで測った、作る量と使う量の差」。線がどちらに動くかを考えれば答えが出る。

98つのケースを1つのルールで

8つのケースは丸暗記するものではありません。次のルールを当てはめれば、すべて自分で導けます。

ルール：消費は「今年の所得」ではなく「恒常所得（一生をならした所得）」で決まる 今年だけ宝くじが当たっても、生活水準はあまり変えない（一時的）。
昇給して給料が今後ずっと上がるなら、生活水準を上げる（恒常的）。
来年からの昇給が決まったら、今のうちから少し使い始める（将来）。
作る量 Yˢ は動くか？
使う量 A（特に恒常所得で決まる消費）は動くか？
差 Yˢ − A がどう変わるかを見る
一時的な産出量の増加作る量 増 ／ 使う量 不変 → 純輸出 増える（図5.6）

恒常所得がほとんど変わらないので、消費は変わらない。余った分を輸出する。

恒常的な産出量の増加作る量 増 ／ 使う量 同じだけ増 → 純輸出 不変（図5.7）

恒常所得が増えた分だけ消費も増える。2本の線が同じ幅だけ右へ動く。

将来の産出量の増加作る量 不変 ／ 使う量 増 → 純輸出 減る（図5.8）

恒常所得が上がり、消費が先に増える。

資本の限界生産物の増加作る量 はじめ不変 ／ 使う量 増 → 純輸出 減る、やがて改善

機械の生産性が上がって投資が増える。資本が積み上がると生産が増え、貿易収支は少しずつ改善する。

この考え方は 課題 (d) で使います

世界利子率の上昇作る量 不変 ／ 使う量 減 → 純輸出 増える（図5.9）

外国の投資ブームなどで世界利子率が上がると、自国ではお金を借りにくくなり、貯める得も増える。消費と投資が減る。A線そのものは動かず、線の上を左上へ移動する。

世界利子率の低下作る量 不変 ／ 使う量 増 → 純輸出 減る

上の逆。消費と投資が増えて、使う量が作る量を上回る。

この考え方は 課題 (a)・(c) で使います

一時的な政府支出の増加使う量 増 → 純輸出 減る（図5.10）

政府が今年だけ多く使う。家計の生涯の税負担はほとんど変わらないので、消費は変わらない。国内で使う量が増えたのに作る量は同じなので、不足分を輸入し、貿易赤字が政府支出の増加分だけ広がる。

恒常的な政府支出の増加使う量 不変 → 純輸出 不変（図5.11）

政府がずっと多く使うなら、その分ずっと増税が必要になる。家計の手取りの恒常所得が同じだけ減り、消費も同じだけ減る。政府が使う分と家計が我慢する分が打ち消し合う。

一時的な減税使う量 不変 → 純輸出 不変（図5.11）

今年の手取りは増えるが、政府の支出は同じなので、いずれ増税で穴埋めされる。家計がそれを見越して増えた分を貯めておけば、消費は変わらない。これをリカードの等価定理といい、開放経済でも成り立つ。ただし家計が本当にそこまで先を読むかには議論があり、これはモデル上の結論。

10赤字はいつまで続けられる？（通時的予算制約）

借金はいつか返さなければならないので、貿易赤字を永遠に続けることはできません。これを、今年（第1期）と来年（第2期）だけの2期間モデルで確かめます。

準備：割引現在価値

利子率が10%なら、今の100万円は1年後に110万円になります。逆に言えば、1年後の110万円は今の100万円と同じ価値です。1年後の金額を今の価値に直すには (1 + r) で割ります。これを割引現在価値といいます。

1年後の金額110
÷ (1 + 0.1)÷ 1.1
今の価値100

ルール：純輸出の割引現在価値の合計はゼロ

最初の対外純資産がゼロ（B₁ = 0）で、2期目の終わりに貸し借りを清算するとします。

NX1 + NX2 / (1 + r) = 0テキスト (5.13)、B₁ = 0 の場合

今年の赤字は、来年の黒字（利息込み）で必ず返す

スライダーで今年の純輸出と利子率を変えると、来年に必要な純輸出が計算されます。

どんな国が先に赤字を出すのか

式を「使う量」で書き直すと、「今年と来年に使う量の割引現在価値の合計は、作る量の割引現在価値の合計（＋初期の資産）を超えられない」となります（テキスト (5.14)）。そのうえで、生涯所得の合計が同じ二つの国を比べます。

F国G国
所得の流れ今は高所得、将来は低所得今は低所得、将来は高所得
人にたとえると定年前に稼ぎ、老後に備える人奨学金で学び、就職後に返す学生
第1期貿易黒字で外国に貸す貿易赤字で外国から借りる
第2期貿易赤字で取り崩す貿易黒字で返済する
えっ、赤字の国が「弱い国」とは限らないの!?

どちらの国も、毎年使う量をならして（平準化して）いるだけです。つまり貿易赤字や対外債務があるからといって、その国の経済が弱いとは限りません。成長が見込まれる国は、今の所得以上に使えるのです。

ただし将来の所得は不確実です。巨額の債務を抱えた国の成長に疑いが広がると、急にお金を貸してもらえなくなり、債務危機に陥ることがあります。

赤字は「将来の黒字で返す約束」。一時的な赤字は問題ないが、永遠には続けられない。

12確認問題

答えを考えてから「解答を見る」を押してね。全問正解をめざそう！
Q1ある国で Y = 600、C = 380、I = 120、G = 120 のとき、純輸出はいくら？黒字か赤字か？
A = 380 + 120 + 120 = 620。NX = 600 − 620 = −20。使う量が作る量を上回っているので、貿易赤字。
Q2対外純資産が200、利子率が2%、貿易収支が −3 のとき、経常収支は？
利息 rB = 0.02 × 200 = 4。CA = 4 + (−3) = +1。貿易収支は赤字でも、利息の受け取りが大きいので経常収支は黒字。
Q3国民貯蓄が90、国内投資が110のとき、経常収支はどうなる？
CA = S − I = 90 − 110 = −20。足りない20を外国から借りて投資している。
Q4小国で、今年だけ大きな自然災害があり生産が落ち込んだ。純輸出はどう動く？
一時的な産出量の減少。恒常所得はあまり変わらないので消費は変わらず、A は動かない。作る量だけが減るので、純輸出は減少する（貿易収支が悪化）。
Q5政府が防衛費や社会保障費を今後ずっと増やすと決めた。モデルでは純輸出はどう動く？
恒常的な政府支出の増加。将来にわたる増税で恒常所得が同じだけ減り、消費が減るので、A は変わらない。純輸出は不変。
Q6利子率が5%で、今年 −50 の貿易赤字を出した（B₁ = 0）。来年はいくらの黒字が必要？
NX₂ = 50 × 1.05 = 52.5。−50 + 52.5 ÷ 1.05 = 0 となる。

総供給 YS は利子率の増加関数利子率が上がると、国内で作る量が増える。テキストと違う、この課題だけの仮定。

なぜ利子率が上がると作る量が増えるのか

利子率が高いときは、今働いて稼いだお金を貯金すると、たくさん利息が付きます。そこで人々は「今多めに働いて、将来は少し休もう」と考え、今の労働が増えて生産も増えます。第4章で学んだ労働の異時点間代替です。テキストの第5章はこの効果を省いていましたが（p.112）、課題ではそれを入れています。

使う道具

  • 財市場のグラフ（(a)(c)(d) で使う）：純輸出 NX = YS(r₀) − A(r₀)。ただし今回の YS は垂直ではなく右上がり。復習：パート3「グラフで動かしてみる」
  • 貸付資金市場のグラフ（(b) で使う）：経常収支 CA = S − I。最初の対外純資産を0とすれば CA = NX。復習：パート1「貯蓄の行き先」

14(a) 一時的な政府支出の増加

問題

一時的な政府支出の増加は、純輸出にどのような影響を与えるか。グラフを用いて説明せよ。

ヒントA線はどちらに、どれだけ動くでしょうか。小国なので r₀ は変わりません。r₀ が変わらないとき、Yˢ の線が右上がりであることは、作る量に影響するでしょうか。

復習：パート3「8つのケースを1つのルールで」（財政政策）

解説と答案例は、まだ公開されていません。

手順1何が変わり、何が変わらないかを確かめる

政府支出が「今年だけ」ΔG 増えたとします（Δ は「変化した量」という意味の記号）。

項目変わる？理由
政府支出 GΔG 増える問題の設定そのもの
消費 C変わらない一時的な支出なので、家計の生涯の税負担はほとんど増えない。恒常所得 YP が変わらず、利子率も r₀ のまま
投資 I変わらない投資は利子率で決まり、r₀ は変わらない
作る量 YS変わらない右上がりの線そのものは動かない。利子率も r₀ のままなので、線の上の位置も同じ
世界利子率 r₀変わらない小国の仮定

手順2グラフのどの線が動くか

使う量 A = C + I + G のうち G だけが増えるので、A の線が ΔG だけ右へ平行移動します。YS の線は動きません。

答案にグラフを描くときの手順

  1. 縦軸に r、横軸に「量（YS, A）」と書く。
  2. 右上がりの線 YS と、右下がりの線 A を描く。
  3. 縦軸の r₀ から横に点線を引く。
  4. A を右へずらした線 A' を描き、矢印と「ΔG」を書き込む。
  5. r₀ の点線の上で、YS との交点と A' との交点の間を「NX < 0（貿易赤字）」と示す。

手順3r₀ の高さで読み取る

利子率は r₀ のままなので、同じ高さで横に読みます。

  • 作る量：YS(r₀) のまま
  • 使う量：A(r₀) から A(r₀) + ΔG に増える

使う量だけが増えたので、足りない分を外国から輸入します。NX = YS − A は ΔG だけ減ります。

数値例で確かめる（G を 20 → 30 に、ΔG = 10）
作る量 YS(4)90（変わらず）
使う量 A(4) = 50 + 20 + 30100（10増える）
純輸出 NX = 90 − 100−10

手順4「右上がりの Yˢ」は答えに影響するか

課題では YS が右上がりになっていますが、(a) の答えはテキストの設定（垂直線）と同じです。YS が利子率で変わるとしても、小国では利子率が r₀ から動かないので、作る量も変わらないからです。

よくある間違い　閉鎖経済の感覚で「政府支出が増える → 利子率が上がる → 民間投資が減る（クラウディング・アウト）」と書いてしまうこと。小国開放経済では利子率は上がりません。民間投資を押しのける代わりに、純輸出が減る（外国のモノで穴埋めする）のがポイントです。

一時的な政府支出の増加は、純輸出を政府支出の増加分 ΔG だけ減少させる（貿易収支の悪化）。

一時的な政府支出の増加は家計の恒常所得を変えないので、消費 C(YP, r₀) は変わらない。小国の仮定より利子率は世界利子率 r₀ のままなので、投資 I(r₀) も変わらない。したがってアブソープション A = C + I + G は政府支出の増加分 ΔG だけ増え、グラフでは A 曲線が右へ ΔG だけシフトする。

一方、総供給 YS は利子率の増加関数だが、利子率が r₀ で変わらないため、供給量 YS(r₀) は変わらない。純輸出 NX = YS(r₀) − A(r₀) は ΔG だけ減少する。すなわち、国内で増えた需要は外国からの輸入でまかなわれ、貿易収支は悪化する。

15(b) 貸付資金市場から考える

問題

上の問題を貸付資金市場の面から考察せよ。

テキストのヒント：S = Y − C(YP, r) − G であることに注意。

ヒントテキストのヒントは S = Y − C(Yᴾ, r) − G です。G が増え、C と Y が変わらないとき、S はどう動くでしょうか。投資 I は r₀ で決まります。そのうえで CA = S − I を考えます。

復習：パート1「貯蓄の行き先」

解説と答案例は、まだ公開されていません。

手順1貯蓄の式を読む

S = YS(r) − C(YP, r) − G

貯蓄 ＝ 作った量 − 家計が使った分 − 政府が使った分

国全体で見た貯蓄は、作ったもののうち、家計も政府も使わずに残した分です。ここに「一時的に G が ΔG 増える」を当てはめます。

  • YS(r₀)：変わらない（(a) と同じ理由）
  • C(YP, r₀)：変わらない（恒常所得も利子率も同じ）
  • G：ΔG 増える

よって、貯蓄 S は ΔG だけ減ります。政府がたくさん使った分、国内に残るお金が減るのです。これはどの利子率でも同じなので、グラフでは S の線が ΔG だけ左へ平行移動します。

手順2投資はどうなるか

投資 I(r) は利子率だけで決まり、利子率は r₀ のままです。だから投資は変わりません。I の線は動きません。

手順3グラフで経常収支を読む

r₀ の高さで、貯蓄 S が投資 I を下回るようになります。足りない資金は外国から借ります。CA = S − I は ΔG だけ減り、経常収支は赤字になります。

数値例で確かめる（G を 20 → 30）
貯蓄 S = 90 − 50 − 3010（10減る）
投資 I(4)20（変わらず）
経常収支 CA = 10 − 20−10

(a) の純輸出 −10 と同じ数字になりました。

手順4(a) とのつながりを確かめる

最初の対外純資産をゼロとすれば CA = NX なので、(b) の「経常収支が ΔG 減る」は (a) の「純輸出が ΔG 減る」と同じことを、お金の側から見たものです。

メモ：モノとお金は表と裏モノの側：国内で使う量が増え、足りない分を輸入する（純輸出が減る）。
お金の側：国内の貯蓄が減り、足りない分を外国から借りる（経常収支が減る）。
輸入した分の代金を、外国からの借金で払っている、と考えればつながる。

一時的な政府支出の増加は国民貯蓄を ΔG だけ減らす。投資は変わらないので、経常収支（＝純輸出）は ΔG だけ減少し、不足分は外国からの借入れでまかなわれる。

国民貯蓄は S = Y − C(YP, r) − G である。一時的な政府支出の増加は恒常所得を変えず、小国の仮定より利子率も r₀ で一定なので、YS(r₀) と C(YP, r₀) は変わらない。したがって貯蓄は政府支出の増加分 ΔG だけ減少し、貯蓄曲線は左へ ΔG だけシフトする。

投資 I(r₀) は利子率が変わらないため一定である。経常収支は CA = S − I なので ΔG だけ減少する。国内の貯蓄不足は海外からの借入れによって補われる。初期の対外純資産をゼロとすれば CA = NX であり、(a) で得た純輸出の減少と一致する。

16(c) 恒常的な政府支出の増加

問題

恒常的な政府支出の増加は、純輸出にどのような影響をもたらすだろうか。

ヒント恒常的な支出増には、ずっと続く増税が必要です。家計の恒常所得と消費はどれだけ減るでしょうか。

復習：パート3「8つのケースを1つのルールで」（財政政策）

解説と答案例は、まだ公開されていません。

手順1「恒常的」だと何が違うのか

政府支出が今年からずっと ΔG 増え続けるとします。政府はその財源として、毎年 ΔG の増税を続けなければなりません（政府の予算制約）。

家計から見ると、税引き後の所得が今後ずっと ΔG 減ることになります。つまり恒常所得 YP が ΔG 下がるので、消費も ΔG 減ります。

メモ：給料のたとえ今月だけ臨時の出費があっても、生活水準は変えない（一時的）。
でも毎月の手取りがずっと1万円減るなら、毎月の支出を1万円減らす（恒常的）。

手順2使う量 A の中身を見る

政府が使う量は増えますが、家計が使う量は同じだけ減ります。

変化前
消費 50
投資 20
政府 20
変化後
消費 40
投資 20
政府 30

数値例（ΔG = 10）。消費が10減り、政府支出が10増える。合計の「使う量」は90のまま。

どの利子率で見ても G の増加と C の減少が打ち消し合うので、A の線は動きません。YS の線も、利子率 r₀ も変わりません。

手順3グラフで確かめる

2本の線はどちらも動かない。r₀ の高さでの差（純輸出）も変わらない。

貸付資金市場で見ても同じです。S = Y − C − G で、C が ΔG 減り G が ΔG 増えるので、貯蓄 S は変わりません。投資も変わらないので、経常収支も変わりません。

数値例で確かめる（ΔG = 10）
使う量 A = 40 + 20 + 3090（変わらず）
純輸出 NX = 90 − 900（変わらず）
貯蓄 S = 90 − 40 − 3020（変わらず）
(a) との違いに注目　同じ「政府支出の増加」でも、一時的なら純輸出は減り、恒常的なら変わりません。違いを生むのは家計の消費が反応するかどうかです。恒常所得仮説（消費は生涯の所得で決まる）が効いています。

恒常的な政府支出の増加は、同額の恒常的な増税によって消費を同額減らすため、アブソープションは変わらない。純輸出は変化しない。

政府支出が恒常的に ΔG 増加すると、政府の予算制約から同額の恒常的な増税が必要になる。家計の税引き後の恒常所得は ΔG 低下し、消費 C(YP, r₀) は ΔG 減少する。

そのため、アブソープション A = C + I + G では政府支出の増加と消費の減少が相殺され、A 曲線はシフトしない。利子率は r₀ で一定なので、投資と総供給 YS(r₀) も変わらず、純輸出は変化しない。貯蓄 S = Y − C − G も変わらないので、経常収支も変化しない。

17(d) 世界利子率の低下

問題

世界全体の需要が減少し、世界利子率が低下したとする。自国の恒常所得や政府支出、投資関数は変わらないとする。このとき、自国の純輸出はどう変化するか。グラフを用いて説明せよ。

ヒントr₀ の横線が下に動きます。A線の上を動くと使う量はどうなるでしょうか。右上がりの Yˢ 線の上を動くと作る量はどうなるでしょうか。テキストの設定（Yˢ が垂直）と比べて、純輸出の変化は大きくなるでしょうか。

復習：パート3「8つのケースを1つのルールで」（世界利子率）

解説と答案例は、まだ公開されていません。

手順1自国にとって変わるのは「利子率だけ」

世界全体の需要が減ると、世界の財市場で需要が供給を下回り、世界利子率が r₀ から r₁ に下がります（r₁ < r₀）。

問題文には「自国の恒常所得や政府支出、投資関数は変わらない」とあります。つまり、自国のグラフの線（A と YS）はどちらも動かず、横線 r₀ だけが下へ動く問題です。

よくある勘違い　「世界の需要が減る → 外国が自国の製品を買わなくなる → 輸出が減る」と考えたくなります。でもこのモデルでは、自国財と外国財は同じ財で、小国は世界市場でいくらでも売り買いできます。自国に届くのは「世界利子率の低下」という形だけです。結論は同じ「純輸出の減少」でも、理由はまったく違うので注意しましょう。

手順2使う量 A は増える（線の上を右下へ）

利子率が下がると、

  • 投資 I が増える：お金を借りやすくなり、設備投資が割に合うようになる
  • 消費 C が増える：貯金しても利息が少ないので、今使おうとする

線そのものは動かず、A の線の上を右下へ移動して、使う量が増えます。

手順3作る量 Yˢ は減る（線の上を左下へ）

ここがテキストとの違いです。YS は利子率の増加関数なので、利子率が下がると作る量は減ります。利息が少ないと「今がんばって働いて貯金する」得が小さくなり、今の労働が減るからです。

手順4グラフで純輸出を読む

新しい利子率 r₁ の高さで横に読むと、使う量が増え、作る量が減っています。NX = YS − A は両方の理由で減ります。

ΔNX = ΔYS − ΔA < 0

純輸出の変化 ＝（作る量の減少：マイナス）−（使う量の増加：プラス）

数値例で確かめる（r₀ = 4% → r₁ = 2%）
r₀ = 4%r₁ = 2%変化
作る量 YS = 70 + 5r9080−10
消費 C = 70 − 5r5060+10
投資 I = 40 − 5r2030+10
使う量 A（G = 20）90110+20
純輸出 NX0−30−30

テキストの設定（YS が90で一定）なら、純輸出は 90 − 110 = −20。課題の設定では作る量も10減るので、−30 とより大きく減ります。

貸付資金市場で見ても同じです。利子率が下がると貯蓄 S は減り（0 = 80 − 60 − 20）、投資 I は増える（30）ので、経常収支 CA = S − I は −30 になります。

課題の仮定が効いてくるのは (d) だけ。ここを書ければ高得点だよ！

世界利子率の低下により、自国では消費と投資が増えてアブソープションが増加し、同時に総供給が減少する。純輸出は減少し、その減少幅は総供給が利子率に反応しない場合（テキストの設定）より大きい。

世界全体の需要が減少すると世界利子率は r₀ から r₁ に低下する。小国である自国にとって、恒常所得、政府支出、投資関数は変わらないので、アブソープション曲線 A と総供給曲線 YS はシフトせず、利子率の低下に伴って各曲線上を移動する。

利子率の低下により投資 I(r) と消費 C(YP, r) が増加するため、アブソープションは A(r₀) から A(r₁) へ増加する。一方、総供給は利子率の増加関数なので、YS(r₀) から YS(r₁) へ減少する。したがって純輸出 NX = YS(r) − A(r) は減少する。総供給が利子率に依存しない場合と比べると、供給の減少が加わる分だけ、純輸出の減少幅は大きくなる。
